# Methylation

cfDNA methylation-pattern classifier for glioblastoma (GBM), with small-cell lung
cancer (SCLC) as a supporting study.

- `pipeline/` — the code: DMR panel selection, in-silico mixing and training,
  external validation, reporting. Start with `pipeline/README.md`.
- `results/` — performance tables only (no raw data, per-sample scores or donor
  information), produced by commit `e8d5fe5d` (tag `results-e8d5fe5d`).
  `results/README.md` explains them, in Korean.

Input data are not included (size and controlled access).
