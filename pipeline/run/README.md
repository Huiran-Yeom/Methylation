# run/ — 2·3·4단계를 판 단위로 돌리는 드라이버

연구 서버에서 결함 수정 2판(GBM · 폐)과 LUAD 다음 판 1안 · 2안을 돌린 드라이버다. 결과 표(`../results/`)는 이 드라이버의 4단계로 냈다.
2판 폐 · 1안 · 2안은 이 파일들로 합치기 전의 드라이버 셋으로 냈고, 합친 뒤 다섯 판에서 4단계 표가 바이트까지 같은지 맞대 확인했다. 2판 GBM 의 마지막 4단계는 이 드라이버(finish)로 냈다.

| 파일 | 하는 일 |
|---|---|
| `drv.sh` | `bash drv.sh <판> <코드 폴더> <main\|help\|finish>` — 대기열(학습 T · 검증 V) · 관문 · 4단계 표 |
| `profiles.sh` | 판마다 다른 값(환경 · 코호트 · 동시 수 · 패널 · 표 자리 · 사전등록 예외) |
| `lib.sh` | 환경 함수(`env_gbm` · `env_lung` · `env_luad` · `env_luad2`) · `train_cell`(2단계 한 칸) |
| `cv_all.py` | 학습 CV 를 `cv_all.csv` 하나로 모은다 |
| `tables_md.py` · `cv_md.py` | 표의 Markdown 보기판을 만든다. 숫자를 원본과 다시 맞대고, 다르면 멈춘다 |

- **main**: 대기열을 새로 만들고 자리 `NL` 개로 학습 · 검증을 돈 뒤, 관문(모든 칸 n/n · rc 0)을 통과하면 표를 낸다.
- **help**: 돌고 있는 대기열에서 다음 항목을 꺼내 도는 보조 자리(`HID=<번호>`)다. 대기열이 비면 끝난다.
- **finish**: 인자로 준 프로세스 그룹이 끝나기를 기다린 뒤 관문 · 표만 낸다. 주 자리가 보조보다 먼저 끝나 «검증 미완» 으로 멈췄을 때 쓴다.
- 관문의 예외는 판 설정에 사전등록된 것만 쓴다. 1안 · 2안 10런의 100k 한 칸이 그 예외다(«45/48 · 3명 풀 부족» · 1차 지표 5k 밖).
- 동시 수는 `NL_SET` · `NV_SET` · `MEMW_SET` 으로만 바꾼다. 옛 이름(`NL` · `MEMW` · `O`)이 환경에 있으면 멈춘다.

**이 서버의 자리**: `profiles.sh` 의 METH_ROOT(`/ssd_data/…`) · 표 자리(`~/표/…`) · 코드 자리(`~/pub/<코드 폴더>/pipeline`)는 연구 서버의 배치다. 다른 곳에서는 이 값들을 고쳐 쓴다. 단계 하나하나는 `../README.md` 의 명령으로도 돌릴 수 있다.

**표 읽기**: `.md` 는 GitHub 에서 보기 위한 판이다. 원본은 `.txt`(검증 표) · `.csv`(학습 표)다.
